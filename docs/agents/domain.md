# Domain Docs

This is a single-context repository.

Before exploring a domain area:

- Read root `CONTEXT.md` when it exists and applies.
- Read relevant decisions under `docs/adr/`.
- If those files do not exist, proceed without creating them solely for setup.
- Use the terminology defined by `CONTEXT.md` when one exists.
- Surface conflicts with an existing ADR instead of silently overriding it.
